# Contributing

This project is under initial development.

Contributions should:

- preserve the separation between acquisition, normalization, persistence,
  and presentation;
- include tests for behavioral changes;
- avoid committing credentials or private utility data;
- update documentation when public behavior changes;
- consider whether an Architecture Decision Record is required for
  architecturally significant changes.

Run formatting, linting, and tests before submitting changes.
