# Internationalization

## Purpose

Define internationalization conventions and future scope.

**Intended Audience:** Developers, contributors, and maintainers.

English is the default language for this project.

The project should nevertheless be designed so that user-facing content can be
internationalized in the future without redesigning core functionality.

User-visible messages should be separated from internal identifiers where
practical.

Provider names, standards terminology, units, and protocol-defined values
should not be translated when translation would change their technical meaning.

Internationalization support will be expanded as user-facing interfaces are
developed.
