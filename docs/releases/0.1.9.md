# Energy Ingest 0.1.9

**Purpose:** Document the published Energy Ingest 0.1.9 release.

**Intended Audience:** Users, contributors, and maintainers.

## Highlights

Published production release of Energy Ingest 0.1.9 on November 3, 2026.

## Fixes

Consult the merged pull requests and repository history for the
historical 0.1.9 change history.

## Compatibility and upgrade notes

Use the version-matched production package and container image. For existing
installations, preserve MariaDB volumes, credentials, and imported readings.

## Verification

The official release published an installation ZIP and SHA-256 checksum,
alongside the production Docker image. The complete historical CI results
should be consulted at the release's GitHub Actions run.

## Known limitations

Solar production and grid-export reporting are not implemented in the
Home Assistant integration by this release.
